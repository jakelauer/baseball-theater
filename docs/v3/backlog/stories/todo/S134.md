**Gap:** The owner asked for a fan-facing page of what changed in each release (owner, 2026-11-08: *"I need a user-facing changelist page which lists the changes in each release simplified to just those things which impact users"*), and named it the change log (owner, 2026-11-10: *"Change list is never right. Change log is the right name."*). S132 serves each release's approved notes, and nothing in the app shows them.

**Impact:** Before S134, a fan had no way to see what changed in a release. S134 impact: one page lists every release since v4.0.0, the public launch, in plain words — the big additions, the other changes that matter, and one line for the small fixes.

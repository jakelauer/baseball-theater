**Gap:** S123's ratified calendar (shell-scoreboard A8, "Favorite teams' off-day mark", `A8.md:81`) marks a day some or all of the fan's favorite teams don't play: a red ✕ when none of them plays, a yellow ✕ when at least one plays but not all, and a tooltip naming those off ("Off day: Yankees, Mets"). S125 AC 2 reads them through "S136's domain function that lists the favorites off that day", but S136 shipped only `dayHasFavoriteTeam` (`packages/domain/src/schedule-month.ts:89`), a yes/no that answers the reverse question (does a favorite play), which nothing outside its tests calls. S125's fence has no `packages/domain`, so the list and the colour would end up worked out in the view (ADR-025).

**Impact:** Before S159, nothing worked out which of a fan's teams have the day off. S159 impact: one tested function says which favorites are off each day and whether the calendar marks the day red or yellow, ready for the calendar (S125) to draw.

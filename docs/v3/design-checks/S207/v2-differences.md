# S207: v3's Box room against the live baseball.theater (v2)

The owner, 2026-11-25: _"the box score system on the live v2 site is a great design to follow. Look at a bunch of different games on it and see the ways your design differs (excluding theme) and try to match it."_ and _"S206 should match baseball.theater's live site, but styled to look like v3"_.

Compared on 2026-11-26: the live site (`https://baseball.theater/game/_/<gamePk>/BoxScore`, v2) read in a browser at desktop (1400 px) and phone (390 px) widths, beside v2's code in the `baseball-theater-legacy` repository (`client/src/Areas/Game/BoxScore.tsx`, `client/src/Areas/Game/Components/BoxScoreTeam.tsx`, `client/src/Areas/Game/Components/MiniBoxScore.tsx`; read, never copied), and v3's Box room before S207 (`web/src/components/game/BoxRoom.tsx` at `f0a6b3e2`). Theme (colours, fonts, the team-coloured section bars, row height) is left out, as the owner asked.

## Games compared

- `823823` CHC @ MIA, 2026-09-05, 6-5: ten pitchers, a caught stealing, substitutes with lettered notes (already recorded).
- `776836` TOR @ COL, 2025-08-06, 20-1: the blowout (COL used seven pitchers).
- `776897` TEX @ SEA, 2025-08-02, 11 innings: the extra-innings game and the game with many pitchers (fifteen), numbered and lettered notes, a balk.
- `776854` TOR @ COL, 2025-08-05, 10-4: errors (four), stolen bases and a pickoff.
- `777861` CLE @ MIN, 2025-05-19, suspended that night and finished on 2025-05-21: the suspended game (no game in the 2025 regular season was left postponed or suspended: each was played later under its own number, so the live site shows each as final).

Each was recorded with `BT_USE_LIVE_MLB=1 pnpm --filter @bt/functions record-fixtures -- --date=<day> --game=<gamePk>` (S14's recorder), then mapped again offline from that recording with this story's mappers; `fixtures/game-<gamePk>.json` and `fixtures/plays-<gamePk>.json` are committed and bundled in `functions/src/adapters/fixtures/bundled.ts`.

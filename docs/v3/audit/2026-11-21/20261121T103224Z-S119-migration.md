Wrangler run non-interactively in CI overrides an existing DNS record for a custom domain, so the owner's first merge of `stage` into `main` would move `baseball.theater` off the Elastic Beanstalk (v2) site at once. The owner, 2026-11-07, on what the real production release gate is: *"changing the DNS away from the elastic beanstalk destination"*. **Impact:** Before S119, the first release of the new app would have silently replaced the current baseball.theater site the moment the owner merged into `main`.

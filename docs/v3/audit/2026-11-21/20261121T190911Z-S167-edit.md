The month answer's days (`ScheduleDayCount`, `packages/domain/src/schedule-month.ts:30`) carry only `date`, `count` and `teamIds`; the stored schedule game (`ScheduleGameSummary`, `packages/domain/src/types.ts:300`) drops MLB's `gameType`, which the upstream type models (`packages/mlb-api/src/schedule.ts:52`) and `mapScheduleGame` (`functions/src/mappers/schedule.ts:166`) never copies; and the month query (`listGameCounts`, `functions/src/adapters/postgres/repos.ts:102`) reads only the game count and team IDs.

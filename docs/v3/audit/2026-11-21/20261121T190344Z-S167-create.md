**Gap:** S159's off-day mark may fall only on a day with a regular-season game (owner, 2026-11-21, asked "Once a favorite team's season is over (eliminated, or no postseason), should later days in that same month stop being marked as its off days?": answered *"Only during the regular season"*), but nothing BT serves says which days those are. The month answer's days (`ScheduleDayCount`, `packages/domain/src/schedule-month.ts:30`) carry only `date`, `count` and `teamIds`; the stored schedule game (`ScheduleGameSummary`, `packages/domain/src/types.ts:300`) drops MLB's `gameType`, which the upstream type models (`packages/mlb-api/src/schedule.ts:52`) and `mapScheduleGame` (`functions/src/mappers/schedule.ts:166`) never copies; and the month query (`listGameCounts`, `functions/src/adapters/postgres/repos.ts:102`) reads only the game count and team IDs. S125's fence is the web app and S159's is `packages/domain`, so neither can add it.

**Impact:** Before S167, BT couldn't tell a regular-season day from a spring training, All-Star or postseason one when it showed a month. S167 impact: each day of the month says whether a regular-season game was played, so the calendar marks a favorite team's day off only during the regular season.

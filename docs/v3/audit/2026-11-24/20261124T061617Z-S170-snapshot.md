**Gap:** B81 (#81) made BT treat a suspended game (MLB `T`/`U`) as live, so its Live room shows the play so far and ingest keeps polling it for 6 hours, and an in-game delay (MLB `I`, e.g. `IR` "Delayed: Rain") already showed as live. But the UI can't tell either from a game being played: the game top bar (`GameTopBar`, `web/src/components/game/GameTopBar.tsx`) shows the same green "● LIVE" (`LiveIndicator`, `web/src/components/game/LiveIndicator.tsx`), the scoreboard row (`ScoreboardModule`, `web/src/components/scoreboard/ScoreboardModule.tsx`) shows the same green inning, and a start delayed before first pitch (MLB `P`, "Delayed Start: Rain") reads as a plain scheduled game. S157 drew the marker that says so and the owner ratified it (game-shell A7, `docs/v3/visual/game-shell/amendments/A7.md`, 2026-11-22: *"Ratify A7"*); nothing builds it.

**Impact:** Before S170, a suspended or rain-delayed game looked exactly like one being played, and a game whose start was delayed looked like it would start on time. S170 impact: the game page and the scoreboard say "Delayed · Rain", "Delayed start · Rain" or "Suspended · Rain" in gold, so a fan sees at a glance that the game has stopped, or hasn't started, and why.

**Baseline:** **S170** landed (design matched by the owner 2026-11-23): `gameStatusMarker` (`packages/domain/src/game-status-marker.ts`, exported from the index) sorts a game's `codedGameState` and `detailedState` into `live`, `delayed`, `delayedStart` or `suspended` with MLB's reason after its colon (none for `live`), through `normalizeStatusCode` / `isSuspendedStatus`; `LiveIndicator` is now the one game status marker, with a `kind` and a `place` (`topbar` or `row`), `LIVE` a blinking `Accent 2` dot (steady under reduced motion), the others steady gold (`suspended` a ring), and no `text-transform`. `GameTopBar` shows it for a game in progress, delayed or suspended and for a delayed start (a gold marker on its own line under the teams on a phone), and `ScoreboardModule` in a row's status place: the inning for `live`, "Delayed · {inning}", "Suspended · {reason}", "Delayed start · {reason}" in place of the start time. `inningShortLabel` (`inning.ts`, "Bot 7", "Mid 3") shares one private half resolver with `inningLabel`.

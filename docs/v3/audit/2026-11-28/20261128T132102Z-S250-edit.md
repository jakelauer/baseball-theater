**Gap:** BT's tiers still carry v2's split for two features built on MLB's data and video. `entitlementsForTier` (`packages/domain/src/entitlements.ts`) grants `fasterLiveRefresh` from the Backer tier and `savantLinks` (Savant's play and pitch video links) from Pro Backer; each session and `GET /api/v1/me` hand those flags out (`accountEntitlements` in `functions/src/services/accounts.ts`, through `effectiveEntitlements`, which hands out the account's stored `entitlements` row, whose `faster_live_refresh` and `savant_links` columns hold `false` below those tiers); and the spec's `Entitlements` schema (`openapi/bt-api.v1.json`) lists them with no word on who gets them. Nothing gates on either flag today: outside the code that builds, stores, types and tests entitlements, no file reads them, so no fan sees a difference. What is wrong is what BT says it sells. Every Stats API answer carries a notice pointing to MLB's `http://gdx.mlb.com/components/copyright.txt`, which reads *"Only individual, non-commercial, non-bulk use of the Materials is permitted…"* (read 2026-11-28). A legal research note the owner read on 2026-11-28 (research, not legal advice) ranked paid gates on MLB-sourced features a medium risk, because selling MLB's data or video for money is the evidence that BT's use is commercial, and suggested making faster live refresh and the Savant video links free. The owner: *"I want to do all your suggestions except redrawing the fields (which I'll do but not yet)."* (2026-11-28). FEATURES records the change in its Tiers table and its **Free vs paid** row, in the same change set as this story; it frees these two perks only, and says nothing yet about the rest of what BT charges for. Faster live refresh, besides, no longer names anything of its own: live games already push every update to every fan over the live connection (S149, ADR-020), so FEATURES makes that push the faster refresh and `fasterLiveRefresh` stays only for compatibility (owner, 2026-11-28, asked *"What should 'faster live refresh' mean now? Live games already push every update to everyone over the live connection (S149, ADR-020)."*, chose *"Retire it (Recommended)"*: *"FEATURES says the live push is the faster refresh, and S250's flag stays only for compatibility."*); no later story gates on it. What supporters get, if anything, is not this story's: the owner is reconsidering tiers altogether (2026-11-28: *"I'm not sure I even want tiers"*), and S256 decides it.

**Impact:** Before S250, BT's account data told every signed-in fan that faster live updates and Savant's video links were perks for paying supporters. After S250 they are free for every fan.

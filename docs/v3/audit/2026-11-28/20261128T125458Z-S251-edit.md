**Gap:** S151 restored the video player's Download button: `PlayerActions` (`web/src/components/videos/PlayerActions.tsx`) draws it for any clip whose MP4 is on MLB's clip hosts (`isMlbClipMp4` and `MLB_CLIP_HOSTS`, `packages/domain/src/video-quality.ts`) while the service worker in control answers its ping (`useDownloadRoute`, `askDownloadRoute`), and the worker (`web/src/pwa/download.ts`, wired in `web/src/pwa/sw.ts`) answers `/download/clip` by streaming MLB's file to the device as an attachment, a whole condensed game included. MLB's Terms of Use (last updated March 11, 2025, read 2026-11-28), §1, allow *"downloading one copy … on any single device for your personal, non-commercial home use"*. A legal research note the owner read on 2026-11-28 (research, not legal advice) ranked clip download the highest risk BT carries: MLB registers its telecasts, so video is where statutory damages exist, and a button built to save MLB's files, long-form condensed games included, which MLB sells access to, is the story a plaintiff would tell. It offered two changes: the cheapest kept Download for short highlights only, with a "for your personal use" line; the safest replaced Download with an "Open at MLB" link. The owner first answered *"I want to do all your suggestions except redrawing the fields (which I'll do but not yet)."* (2026-11-28), and then, asked whether to keep the cheapest Download option (short highlights only, personal-use line) or the safest (drop Download, replace it with "Open at MLB"): *"Let's ditch the download option. We already have the direct link"* (2026-11-28). So Download goes, with the worker route and the domain check that only it used; the palette's Direct link, which opens MLB's own file in a new tab, stays as it is. The link to MLB's page for each clip is S253's to build, with no design (owner, 2026-11-28: *"S252 needs no design"*).

**Impact:** Before S251, the video player had a Download button that saved MLB's video file to the fan's device, a whole condensed game included. After S251 there is no Download button; Direct link still opens MLB's own file, as before.

**Gap:** BT orders a game's videos by its own rule (Impact curation Phase A, S98: `rankHighlightsByImpact` in `packages/domain/src/impact.ts`, by the win probability each clip's play added), and FEATURES' Phase B is a model that ranks them better. A ranking model learns from what fans actually watch, and BT records nothing about that: no count of which clips are started or watched to the end. The research the owner read on 2026-11-22 (`docs/v3/AI-RESEARCH-2026-11.md`, §5 row 6 and §6 step 3) says to start counting now, so that a ranking model can be trained after about a season (S185). The owner put the eight AI ideas in the backlog (owner, 2026-11-22: *"1, 2, 3, 4, 5, 6, 7, 8 should go into the backlog."*), model-assisted highlight ranking among them, as API features for now (*"Oh ok, fair. I would say we can just make these API features for now."*).

**Impact:** Before S174, BT had no idea which videos fans actually play or finish. S174 impact: BT keeps an anonymous daily count, per video, of how often it was started and how often it was watched to the end, with nothing about who watched, so a later model can learn which clips fans want to see first.

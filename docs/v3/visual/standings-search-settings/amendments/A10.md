# A10 — Every player links to its game and its play as pills (S127)

**DRAFT — not ratified.** Shown to the owner for ratification; nothing here binds a build until the owner ratifies it in session and the Ratification section below records it.

Amends the ratified [standings-search-settings design](../DESIGN.md) (ratified 2026-10-14) and its amendments [A1](A1.md)–[A9](A9.md), and, for the day digest's player and the stage-mode player, the players the [shell-scoreboard](../../shell-scoreboard/DESIGN.md) and [game-shell](../../game-shell/DESIGN.md) surfaces draw. Story **S127**; built by the stories the design intake review this ratification triggers slices (S5 re-scoped, or a story sliced after it, for Search's player; a sliced story each for the day digest's and the stage players), each reusing S145's `PlayInningPill`.

**Adds:** a game pill, `More from game →`, at the top left of every floating player opened outside a game's own Videos room (Search's and the scoreboard day digest's), before game-shell A6's inning pill (`Top 6 →`) for a clip with a play; and the inning pill in the stage-mode player, on its own row above the video, for a clip with a play.
**Overrides:** A6's `search-playing-floating-mobile`: its "Go to game: NYY @ BOS, Sep 21 →" link becomes the `More from game →` pill, followed by the inning pill for a clip with a play. The day digest's player's "Go to game: … →" link (the v3.2.1 build; shell-scoreboard draws no frame of it) the same way. game-shell A6's **Overrides** line and **Where else** bullet, which put the inning pill after "Go to: Game →" in Search's floating player: there is no "Go to:" label and no text game link, the game link is the `More from game →` pill (owner, 2026-11-19, quoted under Decisions). The stage player of game-shell's `video-player-stage-*` frames gains the inning pill row; nothing else in it changes.
**Repeals:** the "Go to game: … →" text link in every player, the "Go to:" label, and the `•` separator and "At-Bat →" link of the owner's 2026-11-07 wording.

## Decisions

The owner's words, as given. On 2026-11-07: "S127: make it “Go to: Game ->  •  At-Bat ->” instead of the one link that us there now, but with actual arrow Unicode characters". On 2026-11-19, asked whether game-shell A6's pill replaces the At-Bat link in Search's player: "Game link + pill". Asked whether the play's inning pill should also appear in the day digest's player and the stage-mode player: "all players always". Asked whether a `•` stays between "Go to: Game →" and the pill: "Change Game -> to a pill as well, but change the label to "More from game ->" and link to the videos tab of that game, and remove the "Go to:" label". Asked what a screen reader says for the inning pill: ""Open play - Top of 6th inning"". Asked whether a clip that belongs to no game should show the "More from game →" pill: "No pill (Recommended)".

The bullets below are the choices made while drawing, offered with the draft; they become the owner's only when the owner ratifies it.

- **Inning pill:** every inning pill in these frames is an instance of game-shell A6's `play-inning-pill` component (Figma 724:10189, on the Components page), unchanged: the play's half-inning as a number and the Unicode arrow `→` (U+2192), `Top 6 →` or `Bot 3 →`, in the date's muted text on `color/bg/raised`. It is not drawn again anywhere.
- **Game pill:** `More from game →`, with the Unicode arrow `→` (U+2192), never `->`. It is an instance of the same `play-inning-pill` component (724:10189) with only its text overridden, so it has the inning pill's size, fill, text colour, hover and focus (game-shell A6's Colour and Hover and focus bullets), and a change to the component reaches both pills. The component is not edited by this amendment.
- **Order:** the game pill first, then the inning pill 8px after it, on one row at the player's top left; "Close ✕" stays at the top right. Both pills fit the 358px mobile row on one line.
- **No play:** a clip with no play shows `More from game →` alone (the owner confirms this when ratifying, as S127 AC 1 asks).
- **No game:** a clip with no game (`gamePk: -1`, S5's notes) has no play either, so it shows no pill; the top row keeps only "Close ✕" at the right (owner, 2026-11-19: "No pill (Recommended)").
- **Videos room:** the floating player opened from a game's own Videos room keeps only the inning pill (game-shell A6's `video-player-dialog-playmeta-*` frames, unchanged): the game is already open, so it has no game pill.
- **Stage player:** the stage-mode player follows the context it plays in. Today it plays only in a game's Videos room, so it shows the inning pill alone, on a row of its own above the video (the stage has no top row to hold it), left-aligned with the video; a clip with no play shows no row. Were a stage player ever to play outside a game's Videos room, it would show both pills, as the floating players there do.
- **Opens:** **More from game →** opens that game's Videos tab, `/game/:gamePk/videos` (the `/game/:gamePk/:tab` route in `web/src/routes.tsx`), not the game's default tab as "Go to game" did. The inning pill opens the Plays room on that play, its at-bat open and marked (game-shell A5, unchanged by game-shell A6). Each pill closes the player as it navigates, as the game link does today; in the stage player the inning pill leaves the Videos room for the Plays room, so the stage stops with the room.
- **Accessible names:** the inning pill's is S145's `Open play - <Top|Bottom> of <ordinal> inning`, e.g. `Open play - Top of 6th inning` (owner, 2026-11-19). The game pill's is proposed as `More videos from <game label>`, e.g. `More videos from NYY @ BOS, Sep 21` (the game label the player's link shows today); the owner settles it when ratifying.
- **Rest of the player:** unchanged: the video, its controls, the title, the disclaimer, "Close ✕" and the fully opaque scrim of A6. Hide Scores doesn't change the pills (Search is unaffected by it, owner, 2026-10-21; the inning carries no score).

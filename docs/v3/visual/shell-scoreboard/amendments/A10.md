# A10 — The day digest on Raised, ranked down each column (issue #38)

Amends the ratified [shell-scoreboard design](../DESIGN.md) (ratified 2026-10-14) and its [A1](A1.md)–[A9](A9.md). Built by pull request #58 (issue #38, the owner's site-polish list), shipped in v3.2.1. A written amendment: the owner's directions, ratified as words (no Figma frames). The v3.2.1 build is its drawn record.

**Adds:** nothing.
**Overrides:** the day digest ("Best of {date} — Highlights") on every scoreboard frame that draws it, including A3's `scoreboard-digest-hidden-mobile`, A4's `scoreboard-digest-hidden-nonotice-mobile` and A5's `scoreboard-header-version-desktop`, which differ from the build only in the digest; and its gold in DESIGN.md's Decisions and Interpretation. Each digest item is a Raised card with a hairline border (`--bt-raised`, `--bt-hairline`), not the dull-amber gradient; the rank stays in the accent color and the top item keeps its `WATCH FIRST` badge. With two columns (medium and desktop) the ranks run top to bottom, then left to right: the first ⌈n/2⌉ items fill the left column and the rest the right, so five read 1–3 on the left and 4–5 on the right. Mobile keeps one column in rank order.
**Repeals:** the digest gold gradient (`#3A2A0E` base, `#56401A` / `#4E3916` highlights, `#2E220B` darkest).

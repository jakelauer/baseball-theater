# A16 — The shared scoreboard module draws no slot box on a scheduled row (S162)

Amends the ratified [shell-scoreboard design](../DESIGN.md) (ratified 2026-10-14) and its amendments [A1](A1.md)–[A14](A14.md). Story **S162**, a design chore; it changes no rule, only makes the shared Figma components agree with [A7](A7.md) (ratified 2026-11-19). Ratified 2026-11-22. The component edit was a draft until it was ratified, even though every instance in the live file already showed it: the live Figma file is never evidence of what is ratified (CLAUDE.md, "A shared design piece is one Figma component"); the sealed PNGs and ratified amendments are.

**Adds:** two frames, `scoreboard-scheduled-row-mobile` and `scoreboard-scheduled-row-desktop`, each one scheduled row (a game that hasn't started) as the shared `Rich Scoreboard Module` now draws it.
**Overrides:** in the live file only, the shared components every scoreboard frame places: `Rich Scoreboard Module` `State=Scheduled` (163:1612) no longer draws the pre-game slot, and `Modular Block` `State=Pre-Game, Occupant=Win Probability` (71:17) is marked unused. No sealed PNG changes; each ratified frame that drew the pre-game bar on a scheduled row (listed under **Frames reached**) differs from a build only in that row's slot, which A7 already decided.
**Repeals:** nothing beyond A7, whose repeal of the pre-game win probability bar this records in the components.

## Decisions

Recorded as the owner stated them. On 2026-11-16, asked what a scheduled row should show with the pre-game bar repealed (A7): "Remove the box entirely." On 2026-11-19, of the Room Menu occupant on a scheduled row: "Keep the links, but continue to hide recap". On 2026-11-20, asked "Should a design chore update Figma's shared scoreboard module so scheduled rows stop drawing the pre-game win-probability bar that A7 removed?", the owner chose "Yes, a design chore (Recommended)".

- **Scheduled row:** the edit is to the shared component `Rich Scoreboard Module`, variant `State=Scheduled` (163:1612), not the frames or any detached copy: every frame places an instance of it, so each one now shows the change. Its slot (the nested `modular-block` instance, 71:94) is hidden, so a scheduled row draws no slot box. The row's body is unchanged and already holds the probable pitchers beside each team, as A7's `scoreboard-slot-winprob-mobile.png` draws them: `J. Steele (L)` over `11-5, 3.12` beside the Cubs, `F. Peralta (R)` over `10-8, 3.68` beside the Brewers. The row keeps its width, and the left `score-area` keeps its fixed 220px, so the space the box took stays empty rather than the row narrowing (A7, choices made while drawing). The variant is renamed from `Slot=Win Probability` to `Slot=None`, since it draws no slot, and its component description says why.
- **Pre-game slot variants:** `Modular Block` `State=Pre-Game, Occupant=Win Probability` (71:17) is marked unused (its component description says the bar was repealed by A7 and no row places it). It is kept rather than removed because the scheduled row's hidden slot is an instance of it, and A3's Room menu frame swaps that instance to the Room menu; removing the variant would orphan the slot that frame shows. The `Modular Block` set has no separate Status pre-game variant (there is no `Occupant=Status` value): the default Status occupant's pre-game state was this same Win Probability bar (the set's `Occupant` values are `Count`, `Pitchers`, `Win Probability` and `Room menu`; REVISIONS R14a), so marking 71:17 unused retires the Status pre-game variant too.
- **Room Menu:** the Room Menu pre-game variant (`Modular Block` `State=Pre-Game, Occupant=Room menu`, 437:2959) is unchanged and keeps `Videos` · `Plays` · `Box` with no recap (owner, 2026-11-19: "Keep the links, but continue to hide recap"). A reader who chose Room Menu still sees that box on a scheduled row: the one frame that draws it, A3's `scoreboard-slot-room-menu-mobile` (438:3315), keeps its slot visible through an instance override on its row (438:3333), so it shows what was ratified.
- **Frames reached:** every frame that places the scheduled module (the agent's reading of which surfaces each belongs to, from the frame names the ratified files list). On the Scoreboard page: the base frames `scoreboard-mobile`, `-medium`, `-desktop` and `scoreboard-scores-hidden-mobile`, `-medium`, `-desktop` (DESIGN.md, A3, A4); A1's `scoreboard-standalone-mobile` and `scoreboard-offline-mobile`, `-medium`, `-desktop`; A2's `scoreboard-header-desktop`; A5's and A9's `scoreboard-header-version-desktop`; A3's and A4's `scoreboard-slots-hidden-mobile`, `scoreboard-digest-hidden-mobile`, `scoreboard-slots-hidden-nonotice-mobile` and `scoreboard-digest-hidden-nonotice-mobile`; standings-search-settings A4's `scoreboard-deleted-mobile`; A7's `scoreboard-slot-winprob-mobile`, `-medium`, `-desktop` and `scoreboard-slot-winprob-hidden-mobile` (their scheduled rows already drew no box, so they look the same); and A8's 29 calendar frames, `scoreboard-calendar-{closed,open,invalid,offday,loading,offseason,earliest,tooearly,failed}` at mobile, medium and desktop, plus `scoreboard-calendar-short-mobile` and `scoreboard-calendar-offday-hold-mobile`. On the Shell & navigation page: `shell-notice-mobile`, `-medium`, `-desktop` (DESIGN.md, A1, A6); `shell-update-mobile`, `-medium`, `-desktop` (A1, A6); `nav-drawer-mobile`, `-medium` (A2, A12); `shell-signed-out-mobile`, `-desktop` (A2); `shell-version-desktop` (A5, A12); A9's `update-notice-link-mobile`, `-medium`, `-desktop`, `updated-pointer-mobile`, `-medium`, `-desktop`, `updated-pointer-with-marker-mobile`, `-medium`, `-desktop`, `updated-pointer-menu-open-mobile`, `-medium`, `rail-version-release-desktop` and `drawer-changelog-link-mobile`, `-medium`; A12's `account-menu-mobile`, `-desktop`; A13's `live-marker-scoreboard-live-mobile`, `-desktop`; A14's `site-footer-mobile`, `-medium`, `-desktop`, `site-footer-standalone-mobile` and `site-footer-signed-out-mobile`; and the two rows of the `scoreboard-games` piece on that page. A3's `scoreboard-slot-room-menu-mobile` keeps its Room menu slot (**Room Menu**). No frame on the Change log, Game, Standings, Search, Settings or Reference pages places the module. A15's frame is not drawn yet; once it is, it will show the row this way too.
- **Copies:** the file was searched page by page for a scheduled row drawn as a copy rather than an instance (any `J. Steele (L)`, `7:10 PM ET` or `58%` text outside an instance of the module or its slot) and for a `Modular Block` pre-game Win Probability placed outside the scheduled module. None was found: every scheduled row in the file is an instance of `Rich Scoreboard Module` `State=Scheduled`, so none had to be made an instance, and no copies differed.

## Choices made while drawing (accepted at ratification)

- The slot is hidden in the component rather than removed, so A3's Room menu row keeps its slot through an instance override (**Room Menu**, **Pre-game slot variants**).
- The scheduled variant's name now reads `Slot=None`, matching what it draws.
- The two export frames draw only the row, on the scoreboard's ground, at the width each layout gives it; the rest of each page is as the ratified frames already show it.

# A12 — The account icon opens a menu (issue #38)

Amends the ratified [shell-scoreboard design](../DESIGN.md) (ratified 2026-10-14) and its amendments [A1](A1.md)–[A11](A11.md). Built by pull request #58 (issue #38, the owner's site-polish list), shipped in v3.2.1; this amendment draws what was built. **Draft, not ratified.**

**Adds:** the account menu: signed in, pressing the account icon in the header opens a small menu under it, right-aligned to the icon, with two items, **Settings** (gear icon; goes to `/settings`) and **Sign out** (sign-out icon; signs out where you are). It closes when an item is picked, on Escape, or on a press outside it.
**Overrides:** A2's account icon destination, "Settings → Account when signed in": the icon no longer goes straight to Settings, it opens the menu. Signed out is unchanged: "Sign in" beside the icon (A2), which shows "Signing in…" with a spinner once pressed (built with #58). While the session is still loading the header draws no account control at all, so it doesn't flash.
**Repeals:** nothing.

Source: https://www.figma.com/design/wqGKEFlvyxq0ObWZhRJdPF?node-id=658-19927 — section "AA — Account menu (A12, draft 2026-11-16, awaiting ratification)" on the Shell & navigation page, live file as edited in this session (no named version).

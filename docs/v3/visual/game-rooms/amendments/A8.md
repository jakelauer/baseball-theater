# A8 — Hide Scores masks the runs in the Box room's pitching table and details (S207)

Amends the ratified [game-rooms design](../DESIGN.md) (ratified 2026-10-14) and its amendments [A1](A1.md)–[A7](A7.md), chiefly [A3](A3.md)'s Box decision. Built by **S207** (pull request #665), which added the Box room's pitching table and box score details under the owner's design exemption. A written amendment: the owner's answers, ratified as words (no Figma frames). The S207 build is its drawn record.

**Adds:** with Hide Scores on, the Box room masks the runs-bearing values of what S207 added, each drawn as the room's hidden value ("–"): in each team's pitching table, every pitcher's R, ER and ERA; among MLB's detail and game lines, the values of the RBI, 2-out RBI, Team RISP and Inherited runners-scored lines (their labels stay). Every other pitching column (IP, H, BB, SO, HR, WHIP) and every other line shows as with Hide Scores off.
**Overrides:** A3's Box decision, read as "Box is unchanged by Hide Scores", for those values only. Everything A3 and A4 draw on the Box room with Hide Scores on stays as drawn: the linescore, the batting table (its R and RBI columns included) and the Game info lines in A3's box-hidden-mobile and A4's box-hidden-nonotice-mobile frames, none of which draws a pitching table, a detail group or a runs-bearing line.
**Repeals:** nothing.

## Frames

None. No frame is redrawn: the values this amendment masks appear in no drawn frame on this surface or any other, so every frame stays as ratified. The S207 build (`web/src/components/game/BoxRoom.tsx`, `isRunsBearingLine` in `web/src/components/game/format.ts`) shows it.

## Decisions

Recorded as the owner stated them.

- On 2026-11-26, asked whether S207 AC 5's hiding of the new runs values or A3's "Box unchanged" should win under Hide Scores: "Hide them (AC 5) (Recommended)". S207 AC 5 reads: Hide Scores hides "the runs-bearing values of the new parts (the pitching table's R, ER and ERA; the `RBI`, `2-out RBI`, `Team RISP` and `Inherited runners-scored` lines)", and "The batting table's R and RBI columns and the linescore stay as A3 has them."
- On 2026-11-28, asked "Ratified game-rooms A3 says 'Box is unchanged by Hide Scores', but on 2026-11-26 you chose S207 AC 5 (Hide Scores also hides the Box room's runs values), and that's how it shipped. Should game-rooms get a text-only amendment (A8) recording that, drafted for you to ratify?": "Draft an A8 (Recommended)" ("The agent drafts a text-only amendment, with no new frames, for you to ratify later.").

## Interpretation

- *Agent:* the frames A3 and A4 drew for the Box room with Hide Scores on stay the drawn reference for everything they show; this amendment adds only rules for values they don't draw. So its **Overrides:** line names those frames in plain text, not as overridden frame names, and a design match of a Box capture with Hide Scores on is still judged against A3's and A4's pictures.
- *Agent:* the masked value is the Box room's existing hidden value (`HiddenValue`, as A3 draws it on the other rooms); no new treatment is drawn or implied.

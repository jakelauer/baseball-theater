title: Every page shows the same score for a game
---

- **Before, the scoreboard could briefly show a score a run behind the game page, or step a score back, because it kept its own copy from a slower MLB source. Now, every page reads a game's score, status and on-field moment from one stored place, and while a game is live only MLB's live feed changes it.** Details: **S150** — a `game_states` table (one row per game, filled from the stored days and games by its migration) written only by `switchGameState`, which hands a game's row to the live feed while it is in its live window and to the schedule before and after it (`gameStateSource`), skipping a feed copy older than the newest feed time it has taken (`FetchedGame.feedTime`, MLB's `metaData.timeStamp`); the day and game reads, the game hub's first send and the ingest's publish serve the joined state, the day's version only rising (`served_base`); API shapes unchanged.

title: The app can fetch every release's approved notes
---

- **Before, the app had no way to ask what changed between releases. Now one request returns the notes the owner approved for every release, newest first, so the change log page can list them, and a release's notes show up within five minutes of it going live.** Nothing fans see changes yet: the change log page comes with later work, and no release has notes until the public launch (v4.0.0). Details: **S132**: `GET /api/v1/releases` (`current`, `releases`; drafts never returned), served from a bundle `pnpm release:bundle` builds from `releases/*.json` with a drift test, cached at most 5 minutes in all, in the OpenAPI spec, with `fetchReleases` in the web client; the release rule in `CLAUDE.md` runs the bundle command when notes land.

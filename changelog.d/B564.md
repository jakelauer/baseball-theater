title: A refresh test no longer fails every night for an hour
---

- **Contributors' checks no longer fail for an hour each night because of one clock-sensitive test.** A refresh test dated its game to MLB's today but let its clock run past midnight US Eastern, so any check run then failed for no fault of the change being checked. Details: **B564** (#564) — `refresh.test.ts` › "counts an unchanged refresh as checked…" pins the wall clock to midday Eastern (`vi.useFakeTimers({ toFake: ["Date"] })`) and derives its stale `fetchedAt` from it, so it passes at any hour.

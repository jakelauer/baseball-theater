- **Before, the Standings page and the server each kept their own copy of the rule for "this table has no teams yet", so a fix to one could miss the other. Now there is one copy, and the server uses the same rule the page does; fans see no change.** Details: **S175** — the standings service (`functions/src/services/standings.ts`) calls the domain's `standingsHasNoTeams` at its four empty-table checks and its private `isEmpty` is gone (ADR-025, enhancement #340); new service tests cover no divisions, divisions with no team and a single team at each check.

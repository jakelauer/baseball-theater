title: The full check on every change to the shared branch passes again

- **Before, one of the code-rule checks could take a little over five seconds to start on a busy build machine, and the test runner gave up at five, so the full check on the shared branch failed even though nothing was wrong. Now those checks get twenty seconds, like the server's tests, and the branch is green again.** Details: **B669** (#669) — `tools/vitest.config.js` sets `testTimeout: 20_000` (the type-aware ESLint rule tests build a TypeScript program on their first case); regression: `tools/vitest-config.test.js`.

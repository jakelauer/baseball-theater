title: Testers can see the site as any backer tier, on the test site only
---

- **Before, the test site could only show Baseball Theater as someone with no Patreon pledge, so nothing meant for patrons could be checked before fans got it. Now, a signed-in tester on the test site picks any backer tier (or none, or their real one) in Settings and sees the site exactly as that patron would.** The choice never changes anyone's real tier or Patreon pledge, and on the real site it doesn't exist at all: the server refuses it there. Details: **S215** — `effectiveEntitlements` decides the tier every session and `GET /api/v1/me` hand out; `GET`/`PUT /api/v1/me/tier-override` (`no-store`, 404 unless `BT_TIER_OVERRIDE` is set beside the mock sign-in, which only `env.staging` does); the choice is stored per user in a new `tier_overrides` table (migration `0005`), included in data downloads and deletion; Settings shows a plain "Testing only (staging): backer tier override" control only when the server offers it.

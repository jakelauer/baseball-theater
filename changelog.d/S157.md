title: Fans will be able to tell when a game is suspended or delayed
---

- **Before, nothing showed how a suspended or rain-delayed game should look, so on the game page and the scoreboard it looked exactly like a game being played, and a game whose start was delayed looked like it would start on time. Now there is an approved design: a steady gold "● Delayed · Rain", "● Delayed start · Rain" or "○ Suspended · Rain" takes the place of the blinking green "● LIVE" on the game page and on the game's scoreboard row, on its own line under the team names on a phone. The app doesn't show it yet; S170 builds it.** Details: **S157** — game-shell amendment A7, ratified by the owner 2026-11-22 after answering its eight open questions; the game top bar's live indicator and the scoreboard row's live status are now one shared Figma component, `game-status-marker`, with a state each for in progress, delayed, delayed start and suspended.

title: The planning scripts work however they are started, and refreshing the plan stays quick
---

- **Before, a planning script started through a linked or temporary folder quietly did nothing and still reported success, and every quick refresh of the local copy of the plan asked GitHub about each open story one at a time. Now the scripts behave the same however they are started, and a quick refresh takes a handful of requests whatever the plan's size.** Nothing in the app changes. Details: **S166** — one shared `isRunDirectly` check comparing real paths (`scripts/backlog-vault/run-directly.ts`, issue #299) in every backlog script with a command line; an incremental `pnpm backlog:sync` lists the open issues before the `since` listing instead of reading each open issue.

- **Before, the approved scoreboard designs still drew a win-probability box on games that hadn't started, though that box had already been removed from the plan. Now every scoreboard design shows an upcoming game the way the app will: its start time, ballpark, teams and probable pitchers, with no box.** Details: **S162** — shell-scoreboard amendment A16, ratified by the owner 2026-11-22; the edit is in the shared Figma `Rich Scoreboard Module` component, so every frame that places it shows it.

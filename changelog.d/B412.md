- **Before, opening baseball.theater jumped to that day's dated address, so search engines saw a home page whose address changed every day. Now the home page shows today's games at baseball.theater itself, with one title that says what the site is; a dated address still shows its own day.** Details: **B412** (#412) — `/` and `/games` render `ScoreboardPage` in place (its undated path already shows the server's default day, S111) instead of `DefaultDay`'s redirect to `/games/<date>`, which is removed; `web/index.html` carries a static title, "Baseball Theater — every game's videos, pitches, plays and box score", and a matching description meta. Regression: `web/src/routes.test.tsx` "default day (S111, #412)" and "home page title (#412)".

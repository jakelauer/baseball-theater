title: A day's scoreboard loads in moments, not half a minute
---

- **Opening a past day's scoreboard no longer makes you wait while every game on it is downloaded; the day now loads about as fast as a game page.** On staging a 15-game day took 25 to 45 seconds the first time it was asked for. Details: **B419** (#419) — the day read's refresh (`getOrRefreshSchedule`) went through `ingestScheduleDay`, which fetched each finished game's full feed (four MLB requests per game, one game after another) and stored it, though the scoreboard answers only from the schedule and the games' stored states; it now refreshes the schedule alone (`refreshScheduleDay`: one MLB request, 6 repository calls instead of 16 MLB requests and 68 repository calls for a 15-game day), and a game is fetched when it is read itself or by the cron's window. The seed paths still store each game through `ingestScheduleDay`.

- **Before, every change since the database-distance measurements stopped reaching the test site (stage.baseball.theater), because Cloudflare refused the region it was asked to run the site near. Now that request names a region Cloudflare accepts, eastern North America, so the test site deploys again and still runs close to the database.** Details: **B629** (#629) — staging's `wrangler.jsonc` `placement.hint` was `aws:us-east-2`, which Cloudflare's upload refuses (`invalid placement hint … [code: 10021]`); it is now `enam`, and a regression test checks any placement hint is one of Cloudflare's region codes.

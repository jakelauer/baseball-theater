title: The game page's top bar line runs the full width

- **Before, the line under a game page's top bar stopped short: it ran only under the room tabs, and never reached the page's edges. Now it runs edge to edge at every screen size, like the line under the site header, with the open tab's red underline still sitting on it.** Details: **B585** (#585) — `GameTopBar` draws the 2px bottom border itself, its negative inline margin undoing the shell main's padding, and with no bottom padding so the tab list overlaps it; `RoomTabList` drops Mantine's own list line (`--tabs-list-border-size: 0`); regression test `e2e/flows/game-topbar-border.spec.ts` measures the border against the content column at phone, medium and desktop.

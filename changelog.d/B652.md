title: The server's tests no longer run the build machine out of memory
---

- **Before, the server's tests kept every throwaway test database open until they finished, so they needed about 11 GB and the full check that every change must pass kept dying for memory on a 16 GB machine, holding up the work behind it. Now each test database is closed as soon as its test is done, and the same run peaks around 3.5 GB.** Details: **B652** (#652) — `migratedPglite` hands each PGlite it opens to a listener (`onMigratedPgliteOpened`) that only the functions tests' setup file (`src/test/use-pglite-snapshot.ts`) sets: an instance opened during a test or its `beforeEach` is closed when that test finishes, one opened in a `beforeAll` or at module level after the file's own `afterAll` hooks; the local server's database is untouched. Regression: `src/test/use-pglite-snapshot.test.ts`.

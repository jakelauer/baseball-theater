title: The review reminder no longer repeats forever in Cursor
---

- **Before, working on Baseball Theater in Cursor, the reminder that a backlog or doc review is due re-sent itself every time the agent stopped, a dozen times in a few minutes, even after the review was done and waiting on its pull request. Now it asks once per change, then lets the agent stop, as it already did in Claude Code.** Nothing a fan sees changed. Details: **B481** (#481) — `scripts/review-gate.sh stop`'s loop guard let a forced turn stop only on Claude Code's `stop_hook_active: true`; Cursor runs the same `.claude/settings.json` hook but sends `loop_count` instead (and sets no loop limit on Claude Code hooks), so the guard never matched. It now accepts `loop_count` above 0 too, still only once per HEAD and due set.

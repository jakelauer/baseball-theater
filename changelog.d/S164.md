title: Every story and bug is now a GitHub issue anyone can search
---

- **Before, the plan's stories lived in files only the team's agents edited, and finished work could only be found by searching the repository. Now every story, open and finished, is a GitHub issue anyone can search: each finished one is closed with a summary of what shipped, linking its code change, pull request, proof and changelog entry, and the repository keeps a record of each story's agreed text, so older checks still prove what was agreed at the time.** Nothing in the app changes. Details: **S164** — `scripts/backlog-vault/github.ts` (the one GitHub module, `pnpm backlog:sync`), `pnpm backlog:migrate` (165 story issues, 5 bugs folded), text records (`scripts/audit.sh create|edit|migration|apply`, ship-time snapshots, `story_snapshot`), the readers swapped to the issue cache, law L9 reworded.
